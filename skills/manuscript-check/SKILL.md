# 書稿健檢工具包

三支 Python 工具，全部**規則式**：每一筆結果都來自寫死的規則或詞表，同樣輸入永遠得到同樣輸出；**只讀稿件、不改稿**，報表另存成 Excel／Word。

| 工具 | 什麼時候用 | 輸入 | 產出 |
|---|---|---|---|
| `稿件健檢.py` | Word 整稿階段 | 一或多個 `.docx` | `稿件名_健檢報表_日期-時間.xlsx` |
| `排版比對.py` | 拿到排版 PDF，確認和定稿一致 | 定稿 `.docx`＋排版 `.pdf` | `定稿名_排版比對_日期-時間.xlsx` |
| `索引頁碼.py` | 正文定案、頁碼不再變動之後 | 索引詞表＋排版 `.pdf` | 索引 `.docx`＋核對 `.xlsx` |

工具與設定都在本 skill 的 `scripts/` 資料夾。以下指令的 `$KIT` 要先設成這個資料夾的實際路徑：

```bash
KIT="${CLAUDE_PLUGIN_ROOT}/skills/manuscript-check/scripts"   # Claude Code plugin 環境
# 其他環境：KIT="<本 skill 資料夾>/scripts"
```

## 開工

1. **確認 Python 與套件**：
   ```bash
   python3 -c "import docx, openpyxl, pdfplumber"
   ```
   失敗時需要安裝 `requirements.txt` 的四個套件（python-docx、openpyxl、pdfplumber、lxml）。**`pip install` 會從網路下載，先問使用者**。Windows 上 `python`／`python3` 可能是 WindowsApps 空殼（執行了沒有輸出），一定要用 import 測試確認。
2. **第一次用或改過程式後**，跑測試（三支都印 `ALL PASS` 才能用）：
   ```bash
   cd "$KIT" && python3 tests/test_all.py && python3 tests/test_collate.py && python3 tests/test_index.py
   ```
3. **「AI 不參與」的稿件**：使用者若指定某份稿件不讓 AI 參與，對那份稿件**只代跑工具、轉述終端機摘要與報表路徑**，不讀稿件、不開報表、不做編輯判斷。要解讀報表前先提醒這會讓 AI 參與，確認後才做。工具本身是本機規則式程式，所以仍可代跑。

## 指令

在 `$KIT` 內執行；路徑有空格或中文時加引號。**工具不會自建輸出資料夾**，用 `--輸出` 前先建好。

```bash
python3 稿件健檢.py 書稿.docx [書稿2.docx ...] [--只跑 標點 簡體 罕用字 異形 結構 統計 外文 文獻] [--輸出 資料夾]
python3 排版比對.py 定稿.docx 排版稿.pdf [--輸出 資料夾]
python3 索引頁碼.py 索引詞表.txt 排版稿.pdf [--輸出 資料夾]
```

所有工具都有 `--設定 路徑`，預設 `設定/設定.ini`。Windows 使用者也可以把檔案拖到對應的 `.bat`。

## 讀報表（給使用者的重點）

- **報表列的是候選，每一筆都要編輯判斷**。工作表名稱前的圈號是整套工具共用的檢查編號（①–⑤、⑧–⑩ 在稿件健檢，⑥ 是索引頁碼、⑦ 是排版比對），稿件健檢的報表本來就沒有 ⑥⑦。回報時先講「總覽」各項筆數，再挑實質問題，不要把整張表貼回去。
- **稿件健檢**：每項一張工作表，附章、段落位置、前後文（命中處以【】標出）。罕用字另有「罕用字清單（交美編）」工作表，可直接給美編確認字型。
- **排版比對**：差異分三級——**實質**（文字、標點、數字不同、漏排、多排、整段漏排，排最前面）、**範圍外**、**排版性**（自動編號、符號字型，通常可略）。
  - 先看「已排除的頁首頁尾」工作表，確認沒有正文被當頁首頁尾排除。
  - 大量「文字不同」：先確認定稿和排版稿是同一版本。
  - 「全形標點錯接」明顯偏高：PDF 文字順序可能讀錯，先對照 PDF 抽看。
- **索引頁碼**：工具找的是「字面出現的所有頁」，不懂同義詞和代稱。請使用者用核對報表的「逐筆出處」抽查誤中，用詞表的「排除詞」剔除後重跑。

各項檢查的細節與限制：`scripts/使用說明.md`。

## 調整（改設定，不改程式）

| 檔案（`scripts/設定/`） | 內容 |
|---|---|
| `設定.ini` | 各項門檻與選項，每項上方有中文註解 |
| `詞表_詞換詞.txt` | 同書異形詞的詞表。內附入門小表，建議換成自己的用字體例 |
| `疊字白名單.txt` | 合法疊字與跨詞界的排除語境 |
| `一簡多繁.txt`、`錯轉.txt` | 簡體殘留清單（與 `zh-tw-guard` 共用，改一份要同步另一份） |
| `譯名表.txt` | 標準譯名與變體 |

同一種誤報反覆出現時，優先加白名單或排除詞，其次才改判斷規則。要改程式時，照 `scripts/維護說明.md` 的流程：先加會失敗的測試、改到全部 `ALL PASS`、記在 `scripts/變更紀錄.md`；工具不得呼叫任何 AI 或雲端服務、不得修改稿件。

## 限制

- 只支援 `.docx`（舊版 `.doc` 先另存）；PDF 必須是排版軟體直接輸出、有文字層的檔案，掃描檔不行。
- 排版比對與索引只支援橫排；已驗證 Word 匯出與 InDesign 輸出的單欄版面。
- 稿件健檢不讀頁首、頁尾與批註；結構檢查需要使用 Word 標題樣式；參考文獻只支援作者—年份制。
