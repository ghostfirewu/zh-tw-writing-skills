# 編輯工具包 使用說明

這是一組規則式的編輯檢查工具，**不使用 AI**。每一筆結果都來自寫死的規則或詞表，所以可以追溯、可以重現。工具只讀取稿件，報表另存新檔，**不會修改稿件**。

## 一、三支工具

| 工具 | 什麼時候用 | 怎麼用 |
|---|---|---|
| **稿件健檢** | Word 整稿階段 | 把一個或多個 `.docx` 拖到 `健檢.bat` 上 |
| **排版比對** | 拿到排版 PDF，要確認和定稿一致 | 把定稿 `.docx` 和排版 `.pdf` 一起拖到 `排版比對.bat` 上（順序不拘） |
| **索引頁碼** | 正文全數定案、頁碼不再變動之後 | 把索引詞表和排版 `.pdf` 一起拖到 `索引頁碼.bat` 上 |

報表預設存在稿件旁邊（索引頁碼例外：存在索引詞表旁邊），檔名後面會加上產生的日期與時間。

## 二、第一次使用：環境檢查

雙擊 `環境檢查.bat`。三項都顯示 `ALL PASS` 就可以使用。

如果顯示找不到 Python 或缺少套件：
1. 到 python.org 下載安裝 Python 3，安裝時勾選「Add python.exe to PATH」。
2. 開啟「命令提示字元」，切換到本資料夾，輸入：`py -m pip install -r requirements.txt`
3. 再跑一次 `環境檢查.bat`。

## 三、稿件健檢

讀取 Word 稿的內文、表格、文字方塊、註腳、尾註。稿件若有追蹤修訂，以「接受全部修訂後」的文字為準。

| 項目 | 檢查內容 |
|---|---|
| 標點 | 引號、括號、書名號沒有成對；中文之間夾半形標點；連續標點；刪節號或破折號只有一個；破折號寫法混用；疊字（的的） |
| 簡體與異常字元 | 簡體字、一簡多繁的可疑組合（以后、里面）、錯轉繁（頭發、關系）、私用區字元、相容字、看不見的字元 |
| 罕用字 | 標準 Big5 沒收的字，附碼位。另有一張「罕用字清單（交美編）」工作表，可以直接給美編確認字型有沒有這些字 |
| 異形並存 | 同一本書裡，詞表的新舊寫法同時出現（身份與身分）；譯名表的變體 |
| 結構 | 章節標題跳號或重號；圖表編號跳號；內文提到但沒有圖說的圖表，或有圖說但內文沒提到的圖表 |
| 統計 | 各章字數；無標點的長串、長句、長段 |
| 外文拼寫 | 全書只出現一兩次、又和高頻詞只差一個字母的外文詞（例：Saccado 對 Saccardo） |
| 參考文獻 | 作者—年份引用和書目雙向比對：引用了但書目沒有、書目有但內文沒引用 |

**報表怎麼看**：「總覽」列出每項的筆數和備註（例如某項為什麼沒有執行）。每一項另有一張工作表，每一筆都附章、段落位置、前後文（命中處以【】標出）和說明，可以用篩選功能逐類處理。報表列的是**候選**，每一筆都要由編輯判斷。

只想跑部分項目時，用命令列：`py 稿件健檢.py 書稿.docx --只跑 標點 簡體`（`py` 換成電腦上可用的 Python 亦可）

## 四、排版比對

去掉空白與換行後逐字比對，所以換行、字距、斷頁都不算差異。頁首、頁尾、頁碼、隨頁註腳會先分開處理。

- 每一筆差異都有**分級**：
  - **實質**：要處理的差異，排在最前面。分類有文字不同、標點不同、數字不同、排版稿少了、排版稿多了、疑似漏段、整段漏排、位置移動、表格內容不同。
  - **範圍外**：排版稿只排了部分內容時，原稿後段整批找不到，會收成一筆。
  - **排版性**：排版造成的差異，通常可以略過，例如自動編號、項目符號、符號字型、表格的閱讀順序。
- 另有兩類只在總覽計數、不列明細：目次的點線引線，以及外觀相同、排版時被統一換掉的字元（例如間隔號・換成．）。這類字元可以在 `設定.ini` 的 `等價字元` 增減。
- **先看「已排除的頁首頁尾」工作表**，確認沒有正文被當成頁首頁尾排除掉。
- 總覽的「全形標點錯接」若明顯偏高，表示 PDF 的文字順序可能讀錯了，請先抽看幾筆、對照 PDF 再判讀。
- 差異出現大量「文字不同」時，請先確認定稿和排版稿是不是同一個版本。

## 五、索引頁碼

### 索引詞表怎麼寫（範本：`設定\索引詞表範本.txt`，也可以用 Excel）
一行一個詞條：`詞條,搜尋詞,參見,排除詞`，後三欄可以省略。

- `治理>多中心治理`：子條目，會縮排排在「治理」之下（「治理」要寫在前面）。
- `歐斯壯,歐斯壯|Ostrom`：中英文或不同譯名合併成同一條（多個搜尋詞用直線 | 分隔）。
- `生態系,,生態系統`：參見，印成「生態系　見 生態系統」。
- `資本,,,資本主義`：排除詞，出現在「資本主義」裡的不算。

用 Excel 時，第一列的欄名寫：詞條、搜尋詞、參見、排除詞。

### 規則
- 頁首頁尾、目次頁不算；註腳裡的出現算在內（可以在設定關掉）。
- 英文詞不分大小寫，而且要完整單字（AI 不會對到 MAIN）。
- 書頁會從頁碼自動換算。換算不對時，在 `設定.ini` 的 `[索引]` 填 `頁碼差`（PDF 頁減書頁），或用 `掃描範圍` 只找正文那幾頁。
- 連續頁會合併成範圍（45–47）。
- 排序：預設照詞表順序；`排序 = 筆畫` 改成依首字筆畫排序（筆畫資料取自 Unicode 官方資料庫），`筆畫標題 = 是` 會加上「【3 畫】」這類標題。
- 找不到頁碼的詞條不會印進索引，會在核對報表的「詞條」表標「找不到」。

### 產出
- **索引（Word）**：可以直接交排版。
- **索引核對（Excel）**：「逐筆出處」列出每次命中的頁碼和前後文，請抽查有沒有誤中（例如找「AI」會連「AI代理」一起算）。誤中的，用詞表的「排除詞」剔除後重跑。
- 工具列出的是「字面出現的所有頁」，不懂同義詞和代稱。哪些頁算實質討論，仍要由編輯從中刪減。

## 六、設定

所有設定都在 `設定\` 資料夾，改完存檔就生效，不必改程式。清單都是 **UTF-8** 文字檔，以 `'` 開頭的行是註解。

| 檔案 | 內容 |
|---|---|
| `設定.ini` | 各項門檻與選項，每一項上方都有說明 |
| `詞表_詞換詞.txt` | 異形並存檢查用的詞表。內附的是入門小表，建議換成自己的用字體例詞表 |
| `疊字白名單.txt` | 合法的疊字，以及跨詞界的排除語境（例：寫「管理理論」，「管理理性」這類「理理」就不會被報） |
| `一簡多繁.txt`、`錯轉.txt` | 簡體殘留與錯轉繁的檢查清單 |
| `譯名表.txt` | 標準譯名與變體 |

## 七、和 AI 助理一起使用

本工具包同時是一支 AI agent skill（見上一層的 `SKILL.md`）。AI 助理可以代為執行工具、判讀報表；也可以指定某份稿件「AI 不參與」，此時 AI 只代跑工具、轉述終端機印出的摘要與報表路徑，不讀稿件、不開報表、不做編輯判斷。

維護工具（修正錯誤、改善檢查規則）時，必須維持規則式與只讀特性（工具不呼叫任何 AI 或雲端服務、不修改稿件），改完要通過測試，並記在 `變更紀錄.md`。細節見 `維護說明.md`。

## 八、已知限制

- 只支援 `.docx`（舊版 `.doc` 請先另存）；PDF 必須是排版軟體直接輸出、有文字層的檔案，掃描檔不行。
- 排版比對與索引只支援橫排。已驗證的是 Word 匯出與 InDesign 輸出的單欄版面，多欄與文繞圖版面尚未驗證。
- 稿件健檢不讀頁首、頁尾與批註。
- 結構檢查需要作者使用 Word 的標題樣式；參考文獻只支援作者—年份制。
- 排版比對的表格只比內容是否相同，不比順序。
- 中文沒有詞界，疊字、一簡多繁、索引詞都可能誤中，請用白名單、排除詞逐步收斂。
