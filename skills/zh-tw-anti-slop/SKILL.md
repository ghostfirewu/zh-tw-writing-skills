# 繁中 AI 腔過濾

## 核心判準（每一句都先過這關）

AI 味的根源是**平庸，不是錯誤**：文法全對，卻靠灌水詞、缺具體細節、以及「換任何同類主題都成立」的假融貫充版面。

> **刪掉這句，讀者少知道哪個具體事實、立場或情緒？沒少＝該刪。**

例：「這款工具無疑為創作者帶來了全新的契機」→ 刪掉後讀者什麼都沒少，刪。「這款工具把排程從五步縮成一步」→ 刪掉讀者就不知道省了什麼，留。

**改寫不加料**：把空話換成具體事實時，**只能用原文或上下文已有的事實**。原文沒有，就刪掉，不替作者編數字、案例或引語。例：原文「大幅提升效率」而全文沒有數字 → 改「提升效率」或刪，**不得**寫成「效率提升 40%」。

## 何時用、用多重

| 情境 | 處置 |
|---|---|
| 自己寫的對外文字（貼文、文案、文章、信件） | 寫完照本清單自查，直接改 |
| 使用者給的稿子，要求「去 AI 味」 | 逐句改，回報改了哪些、為什麼 |
| 書稿、譯稿（作者的作品） | **只標注、不逕改**：列出位置與建議改法，由作者決定 |
| 內部紀錄（筆記、commit message、會議記錄） | 不必套用 |

拿不準算不算對外：看「這段文字本身會不會被第三方讀到」。

## 流程

1. **機械掃描**（有檔案時）：
   ```bash
   python3 ${CLAUDE_PLUGIN_ROOT}/skills/zh-tw-anti-slop/scripts/slop_scan.py 文案.md
   ```
   沒有 `${CLAUDE_PLUGIN_ROOT}` 的環境，改用本 skill 資料夾下的 `scripts/slop_scan.py`。也可以用 `-` 從標準輸入讀。
   掃描器只找**候選**，命中不等於要改：術語（心理學書稿的「療癒」）與字面義（「落地窗」「指紋解鎖」「手工打造金飾」）都不改。判準：換成建議的替代詞後意思變了或變怪，就是字面義。沒命中也不等於沒問題。
2. **通讀判斷**：句型層的問題掃描器多半抓不到，必須自己讀：三項排比湊整、同義詞刻意輪替、極短句戲劇轟炸、格言公式；立場真空只收了「各有優缺點」「因人而異」兩個固定說法，其他寫法要自己找。判準見下方與 `references/rules.md`。
3. **改寫**：照核心判準與「改寫不加料」。
4. **用語**：繁中稿同時跑 `zh-tw-guard`（中國用語、簡體殘留）。

## 最常見的十種（完整清單見 `references/rules.md`）

| 型 | 例 | 改法 |
|---|---|---|
| 灌水動詞 | 賦能、助力、打造、落地 | 換成具體動作（讓…能夠、做出、上線） |
| 墊片詞 | 值得注意的是、說到底、本質上 | 刪掉，讓主語直接發力 |
| 二元對比 | X 不僅僅是 Y，它更是 Z | 直接陳述 Z |
| 開場白套路 | 在現今瞬息萬變的數位時代中 | 刪，從主句開始 |
| 翻譯腔 | 進行調查、被市場所接受、扮演著…的角色 | 調查、獲得市場認可、是… |
| 模糊關聯 | 息息相關、相輔相成 | 寫出誰影響誰，寫不出就刪 |
| 立場真空 | 各有優缺點、因人而異 | 具體選邊；真的中立就刪整句 |
| 三項排比湊整 | 無縫、直觀、強大 | 只留有事實支撐的那一個 |
| 極短句轟炸 | 然後，一切都變了。沒預兆。 | 併回正常句，講實情 |
| 聊天殘渣 | 希望有幫助、好問題！、作為 AI | 全刪（書稿例外：只標注） |

## 回報格式（改別人的稿時）

逐筆列：位置（行或段落）、原句、改後、理由（對應上表哪一型）。只標注的情境（書稿），改後欄寫「建議」。最後一行統計：共幾處、各型幾處。
